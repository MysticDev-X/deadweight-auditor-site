Política de privacidade

Versão 0.2.0 · 26 de outubro de 2026

Em linguagem simples: nada do que a extensão vê sai do teu browser. Não há conta, servidor nosso, telemetria, analytics ou código remoto.

O que a extensão faz

Quando pedes uma análise a uma página, a extensão observa os pedidos de rede desse separador, mede tempos e tamanhos, identifica scripts de terceiros e atribui-os a vendors conhecidos. Se ativares os parâmetros de negócio, calcula uma estimativa de receita perdida — um modelo, não uma medição contabilística.

O que é guardado, e onde

Tudo fica no teu computador, dentro do perfil do Chrome:

  • IndexedDB — sessões: origem e URL da página, data, pedidos observados (URL, tipo, tamanho, tempos), métricas (LCP, TBT, CLS, TTFB, load), cookies e chaves de storage de terceiros observados, resultados, resumo das repetições e comparação local.
  • chrome.storage.local — preferências: parâmetros de negócio, tema e opções de captura.

Não existe sincronização nem backup para os nossos sistemas.

O que nunca acontece

  • Nenhuma telemetria, evento, crash report ou identificador é enviado.
  • Nenhum código remoto: todo o JavaScript e WebAssembly vem do pacote instalado.
  • Nenhuma venda ou partilha de dados — não há dados para vender.
  • Nenhuma leitura fora do separador que pediste para analisar, exceto com as permissões opcionais abaixo.

Permissões, uma a uma

Permissão Para quê
activeTab Acesso temporário ao separador onde clicas em Analisar, só depois do clique.
scripting Injetar o coletor de métricas nesse separador.
webRequest Observar os pedidos do separador analisado, quando há permissão de host.
declarativeNetRequestWithHostAccess Bloquear temporariamente os domínios dos vendors já observados, apenas durante uma comparação pedida por ti e apenas nesse separador. As regras são removidas no fim e no arranque do service worker; a página é recarregada sem bloqueios.
storage Guardar preferências localmente.
sidePanel Mostrar o diagnóstico no painel lateral.

Permissões opcionais

Permissão de host (http://*/* e https://*/*) — necessária para ver pedidos de terceiros e para bloquear temporariamente os vendors na comparação. É ampla, por isso é pedida em runtime, explicada no momento do pedido e revogável em chrome://extensions → DeadWeight Auditor → Detalhes → Permissões do site. Sem ela, a extensão funciona em modo reduzido com o que o PerformanceObserver da página consegue medir.

cookies — ler cookies de hosts de terceiros já observados, apenas quando carregas no botão de verificação no separador Privacidade. Sem esta permissão, a extensão mostra apenas o que a página consegue ver.

Os teus dados, o teu controlo

  • Apagar todas as sessões e preferências nas opções da extensão.
  • Desinstalar a extensão: o Chrome remove os dados associados.
  • Exportar uma sessão para PDF, CSV ou JSON. Os ficheiros ficam onde os guardares; a extensão não os envia para lado nenhum.

Sites analisados

A extensão não altera páginas, não injeta publicidade e não bloqueia pedidos fora do modo de comparação. Nesse modo — iniciado por ti, num separador e por poucos segundos — os domínios observados são bloqueados para medir o efeito, e a página é recarregada sem bloqueios no fim.

Alterações

Qualquer alteração a esta política é publicada nesta página e no repositório do projeto, com a data da versão. Não há versões “silenciosas”.

Contacto

Para questões de privacidade, usa o endereço de contacto publicado na página da Chrome Web Store.
